# Rubik's Cube 3x3 (browser prototype)

A 3D 3x3 Rubik's cube that runs by double-clicking `index.html` — no server, no build step.
Built with plain JavaScript and Three.js (loaded from a CDN at a pinned version).

> Status: work in progress, built in stages.

## Run

Double-click `index.html` (app) or `tests.html` (logic tests) in Windows Explorer.
An internet connection is needed on first load to fetch Three.js from the CDN.
